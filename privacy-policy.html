Privacy Policy - Casebook Atlas Studio

Last updated: 21 October 2026

Casebook Atlas Studio ("the app") is a private desktop tool used only by the owner of the YouTube channel "Casebook Atlas" to manage that channel. It has no other users and is not offered to the public.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app accesses, collects and uses

  • With the owner's permission (Google sign-in), through YouTube API Services: uploads the owner's own videos, thumbnails, captions and playlist entries; posts and reads comments on the owner's own videos; reads the owner's own channel and video analytics (YouTube Analytics API).
  • Through the Instagram API: publishes the owner's own posts and reads the owner's own account insights.
  • The app does not access data of any other YouTube user, except public comments posted on the owner's own videos.

How data is used

Data is used only to publish the owner's content and to build a private performance report on the owner's computer. It is not sold, not used for advertising, and not used to train AI models.

How data is stored

All data, including access tokens, is stored only on the owner's own computer. There is no server and no cloud database. API data is kept for no more than 30 days and is then deleted or refreshed.

Sharing

The app does not share any user data with third parties. Data is sent only to Google/YouTube (and Instagram for Instagram posts) to perform the actions the owner requests.

Cookies and device information

The app does not place, access or recognise cookies or similar technologies on users' devices or browsers, and does not collect device information.

Revoking access and deleting data

You can revoke the app's access at any time at the Google security settings page. After access is revoked, the app's stored tokens stop working and the app deletes stored API data within 7 days. To ask for deletion of any stored data at any time, email universebuffetoffical@gmail.com; it will be deleted within 7 days.
